# PyORM v0.3.0

发布日期：2026-11-24。

本版本修复 `_autosave` 标量字段接受错误类型的问题，提供受版本保护的托管文档删除和显式缓存释放。由于字段类型及注解的运行时语义收紧，版本从 0.2.3 升为 0.3.0。

## 升级注意事项

- `_autosave` 从类注解或默认值推断顶层类型，并在构造、赋值和 BSON 恢复及序列化时校验。`coins = 0` 拒绝字符串、bool 和 float；float 字段不接受 int，也不做数值转换。需要多种类型时声明准确的联合类型。
- 类注解现在决定类型与 nullable。非 Optional 注解的字段拒绝 null；未注解字段保留原有 nullable 规则，显式 Field 参数优先于注解。容器元素参数仍用于编辑器推断，逐元素校验需要显式元素字段。
- 历史异型数据或非 Optional 字段中的 null 会在 `get` / `load` 时抛出 ValidationError。升级前应修正数据或调整声明；迁移期间可显式使用 `Field(default=...)` 保留宽松的 Python 类型规则，BSON 校验继续生效。

完整规则及迁移方案见[字段校验与升级说明](https://github.com/muutot/PyORM/blob/v0.3.0/docs/field-validation.md)。此前错误类型被接受的直接证据属于类型污染，没有证据表明该缺陷曾导致数据丢失。

## 字段与默认值

- 支持 Optional、Union、Annotated 以及声明时可解析的延迟和局部注解。需要 BSON 类型恢复的混合联合声明必须使用自定义 Field codec。
- `_autosave` 中的嵌套实例默认值，以及 `EmbeddedField(..., default=instance)`，独立复制字段和额外数据，使用新锁及新跟踪绑定。
- 默认实例复制保留 Python 容器结构，不重跑业务构造函数或字段默认工厂；已绑定容器复制后不会修改原所有者。根 Document 不能作为可复制的嵌套模板。

## 删除与缓存生命周期

- 新增 `Manager.release(document, discard=False, timeout=10)`。默认确认全部变更落库后释放缓存；`discard=True` 明确丢弃未发送变更，仍等待已有在途及结果不确定的批次确认。
- 新增 `Manager.delete(document, timeout=10)`，托管 `document.delete()` 委托所属 Manager。删除等待已有批次确认，匹配最新确认的版本及写入 token；版本冲突保留缓存和待处理状态。
- 确认记录已被外部删除后，清理该文档的缓存、错误和调度状态，使 Manager 可以正常排空和关闭。删除命令异常保持可见，调用方可重试确认丢失的删除回执。
- 释放或删除成功后，旧文档、容器和嵌套引用继续可读，修改抛出新增并导出的 `DocumentInactiveError`。并发 `get` 等待生命周期操作结束，再共享同一次加载。
- `wait_idle` 和 `close` 等待已经开始的生命周期操作。stats 增加 loading、retiring 计数；集合到模型的注册保留至 Manager 生命周期结束，缓存通过应用显式释放管理。

完整接口、并发和失败恢复语义见[缓存释放与删除](https://github.com/muutot/PyORM/blob/v0.3.0/docs/lifecycle.md)。

## 验证与安装包

本机 CPython 3.13.15 / MongoDB 8.0.4 验证：Rust required 模式 200 项通过；Python off 模式 193 项通过、7 项原生专项跳过。两种模式各执行 28 项真库用例，覆盖在途写入、并发加载、旧引用失效、外部删除与版本冲突、不确定批次确认、超时恢复及关闭期间的删除。Ruff、Pyright 和文档检查通过。

GitHub Release 安装包由 v0.3.0 标签源码经 Actions 构建，以 Python 3.13 / 3.14、两种后端、真实 MongoDB 及隔离安装检查为发布门槛。附件包括一个纯 Python wheel、六个 Windows x64 / Linux x64 / macOS ARM64 原生 wheel、源码包及 SHA256SUMS。安装方式及支持平台见[发布流程](https://github.com/muutot/PyORM/blob/v0.3.0/docs/releases.md)。
